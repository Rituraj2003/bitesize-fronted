# BiteSize Frontend — Micro-Learning React Platform

React 19 + TypeScript + Vite web client for the BiteSize micro-learning platform.

---

## 🏗 Stack Architecture

- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons & Markdown**: Lucide React, React Markdown, React Syntax Highlighter
- **Deployment**: Vercel

---

## ⚙️ Environment Setup

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Set the backend API endpoint:

```env
VITE_API_BASE_URL="https://bitesize-backend.onrender.com/api"
```

---

## 💻 Commands

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run ESLint validation
npm run lint

# Build for production
npm run build
```
